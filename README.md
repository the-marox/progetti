# progetti
## Radar Porcini

Dove e quando cercare funghi in Toscana: https://the-marox.github.io/progetti/radar-porcini/

Il sito sta nel ramo `gh-pages`. Il workflow `.github/workflows/radar-porcini.yml` ogni mattina alle 8:16 UTC
legge le stazioni del Centro Funzionale della Regione Toscana, le previsioni ICON-EU ed ECMWF e il radar della
Protezione Civile, e pubblica i file di dati aggiornati accanto alla pagina.
